# Shopping App (Java)

A simple console-based shopping application written in Java.

## About

This project demonstrates core Java programming concepts including classes, objects, collections, and basic application logic.  
Built as a student learning project to practice object-oriented programming.

## Features

- Product management
- Basic shopping cart / purchase flow
- Object-oriented design (Product class + main application)
- Clean, readable Java code

## Tech Stack

- Java

## Project Structure

```
├── Product.java    # Product model class
├── ShopApp.java    # Main application logic
└── README.md
```

## How to Run

```bash
git clone https://github.com/ankitsapkota2002-boop/shopping-app.git
cd shopping-app
javac *.java
java ShopApp
```
